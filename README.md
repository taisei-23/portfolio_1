■ サービス概要（3行）
・スノーボードを中心としたウィンタースポーツ旅行の計画をサポートするアプリです。

・ユーザーの条件に合わせて最適な雪山や経路・費用を簡単に比較できます。

・費用・移動時間・場所の調整をスムーズにし、ウィンタースポーツのハードルを下げることを目的としています。

■ サービスへの思い・作りたい理由
　私は5歳からスノーボードを続けており、約18〜19年間ウィンタースポーツに親しんできました。
　人に話すと「どれくらいお金かかる？」「おすすめの雪山は？」とよく聞かれますが、私自身は道具が自前だったり家族の車で行くことが多く、正確な費用や時間を説明できず曖昧な回答になりがちでした。
「行きたいけど調べるのが面倒」「どこがいいのかわからない」
　そんな悩みをよく耳にし、この課題を直接解決できるサービスが必要だと感じて企画したアプリです。
　ウィンタースポーツをもっと身近なものにし、より多くの人に魅力を知ってほしいという思いで開発しています。

■ ユーザー層
・ターゲット：若年層のウィンタースポーツ未経験者・初心者

理由：
・スノーボードを始めることが多い年齢層であるため

・「費用」「行き先」「準備方法」といった情報の不足によって初めの一歩を踏み出しにくいため

・情報不足をアプリで補う意義が大きい層のため

■ サービス利用イメージ
・ユーザーはスマートフォンから手軽に利用できます。

・行き先の選択、経路、費用の確認など、旅行前の手間を一括で解消します。

・「どこに行けばいい？」「いくらかかる？」という不安を解決し、ウィンタースポーツの計画をスムーズにします。

■ ユーザー獲得方法（想定）
・アプリ専用のSNS（Xなど）を用意して情報発信

・ウィンタースポーツ初心者向けのコンテンツを投稿し認知を獲得

・開発ログやアップデート情報を発信してファン層を増やす

■ 差別化ポイント・推しポイント

・類似サービスとして 「yukiyama」 がありますが、以下の点で差別化します。

■ yukiyamaとの違い
・yukiyamaは「滑走記録」「雪山コミュニティ」が中心 → 経験者向け

・経路検索・費用計算など旅行計画の機能はない

■ 本アプリの推しポイント
・未経験者・初心者向けに特化

・雪山検索

・経路検索（車・電車）

・費用の概算（高速・レンタル・リフト券など）
→ yukiyamaにはない “旅行計画機能” に強みがあります。

■ 機能一覧（MVPと本リリース）
　■ MVPで作りたい機能（最優先）
　・雪山検索機能（エリア検索・マップ検索）

　・選択された雪山までの経路検索（車・電車）

　・経路ごとの費用計算（高速料金・外部路線検索）

　■ 本リリースまでに追加したい機能
　・周辺宿泊施設の検索・詳細・料金表示

　・レンタルショップ検索（可能なら料金も）

■ 実装予定／技術方針
　■ 雪山検索
　・エリア検索

　・Google Maps Nearby Search API を活用し雪山情報を取得

　■ 経路検索
　・Google Maps API車・公共交通機関のルートを取得

　・公共交通機関は Yahoo!路線検索リンクを表示
　（個人開発では公共交通機関APIが高額のため）

　■ 料金検索
　・車：Google Maps・HERE API・高速料金API（検討）

　・電車：Yahoo!路線検索リンクで対応

　■ 宿泊・レンタル検索（追加）
　・Google Place Details API を利用して施設情報を取得
